# R Programming Labs

Coursework for the R programming module of my Big Data Analytics master's at
AUCA. One folder per assignment.

| Folder | What it covers |
|--------|----------------|
| [`hw1-importing-data`](hw1-importing-data) | Importing data into R from CSV, Excel, SPSS, Stata, SAS, MySQL, a web API, XML and a web page |

## Running the code

Everything is written in R Markdown. Open the `.Rmd` file in RStudio and click
**Knit** to produce the HTML or PDF version.

Each assignment installs the packages it needs the first time it runs, so there
is nothing to set up by hand except the database in HW1 — see that folder's
README for the one command.
